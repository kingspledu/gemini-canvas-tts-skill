# 모델·음성·감정 제작 안내

조사 기준: 2026-11-20. 실행은 **사용자가 API 키를 입력하지 않는 Gemini Canvas HTML만** 사용한다. 아래 API 문서는 기능과 형식의 근거이며 외부 API 실행 지침이 아니다.

## 모델과 호환성

기본 모델은 `gemini-2.5-flash-preview-tts`. [공식 모델 페이지](https://ai.google.dev/gemini-api/docs/models/gemini-2.5-flash-preview-tts)는 텍스트 입력·오디오 출력, 입력 8,192·출력 16,384 토큰을 안내한다. 저지연 음성 합성 및 스타일·속도 조절이 목적이다. 한 장 전체를 한 번에 넣기보다 화자와 감정 전환 단위로 나눈다. 이 패키지의 intensity 숫자는 프롬프트용 편집 척도이지 모델의 보장된 합성 파라미터가 아니다.

현재 [공식 TTS 가이드](https://ai.google.dev/gemini-api/docs/speech-generation)는 새 모델의 speech_metadata와 인라인 태그를 설명한다. **이 새로운 요청 구조와 태그를 2.5의 보장된 문법으로 소개하지 않는다.** 기존 2.5 템플릿은 자연어 연기 프롬프트를 사용한다. 최신 가이드의 예제를 복사해 요청 구조·모델을 자동 교체하지 않는다.

기존 템플릿은 raw PCM 응답을 44100Hz WAV로 변환한다. 새 모델의 완성 WAV와 raw PCM은 다르므로 MIME과 샘플레이트를 검사한다. Canvas가 모델이나 형식을 지원하지 않으면 중단하고 원인을 알린다. 키 입력·Cloud 계정·REST/SDK/CLI·서버 프록시로 우회하지 않는다. Canvas 내부 요청은 네트워크를 사용하며 빈 키 자체가 인증 권한을 주지는 않는다.

## 감정을 설계하는 전략

구간마다 다음 여섯 가지를 작성한다. 문맥에 맞는 2~3개의 핵심 신호를 우선하고 서로 충돌하는 지시를 과도하게 나열하지 않는다.

1. 상황: 누구에게 무엇 때문에 말하는가.
2. 목표: 안심시키기·설득하기·감추기·떠보기 중 지금 하려는 행동.
3. 겉/속 감정: 태연한 척하지만 두려움처럼 공존하는 마음.
4. 전환점: 어느 말에서 감정이 바뀌는가.
5. 소리: 속도·강세·음량·호흡 중 필요한 신호.
6. 끝맺음: 여운·결심·회피와 뒤 구간으로 이어지는 쉼.

`emotion`: 당황 → 감추기 → 작은 결심처럼 원인과 방향을 쓴다.
`acting_notes`: 상대를 안심시키려 웃음을 눌러 말함처럼 행동을 쓴다.
`pace`: 평소보다 약간 느리게처럼 기준을 정한다.
`delivery`: 정상 발성·또렷한 자음·끝을 흐리지 않음.
`pause_after_ms`: 구간 끝 쉼; 내부 쉼은 자연어 지시로 처리한다.

예시: `문 너머 소리를 듣고 겁이 났지만 동생을 안심시키려 한다. 첫 질문은 낮게, “괜찮아”에서는 억지 웃음보다 단단한 말끝. 마지막 문장 뒤 짧은 여백.`

나레이션은 인물을 대신해 매번 울거나 소리치지 않고 사건을 연결한다. 대화는 상대의 직전 말에 반응한다. 독백은 나직한 보통 말소리로, 가까워도 숨만 새는 속삭임·ASMR은 피한다. 중립→의문→긴장→절정→풀림의 곡선을 잡고 절정 앞뒤를 낮춰 대비를 만든다. 한 구간 안에 급격한 감정이 여럿 있으면 구간을 나누되 본문은 보존한다.

## 웃음·기침·울음 등 비언어음

비언어 발성은 목소리의 일부이고, 문 여는 소리·비·폭발 같은 환경 효과음과 다르다. 이 템플릿은 별도 SFX 자산 믹서를 제공하지 않는다. 환경음을 TTS가 정확하게 생성한다고 보장하지 않는다.

| 표현 | 2.5에서 먼저 시도할 자연어 지시 | 검수할 문제 |
|---|---|---|
| 웃음 | 해당 문장 앞에서 짧게 한 번 웃은 뒤 말을 잇는다 | “하하”를 글자로 읽음, 과장·반복 |
| 기침 | 원문의 기침 위치에서 가볍게 한 번 기침하고 바로 대사를 잇는다 | 기침 지시를 낭독함, 여러 번 반복 |
| 한숨 | 답하기 전 짧게 숨을 내쉬고 정상 발성으로 돌아온다 | 과도한 숨소리·긴 침묵 |
| 놀람 | 순간 숨이 멎었다가 짧게 들이쉬고 말한다 | 비명으로 변함 |
| 울음 | 울음을 참아 말끝이 잠깐 흔들리지만 단어는 또렷하게 | 단어 누락, 전 구간 흐느낌 |
| 숨참 | 막 뛰어온 호흡을 한 번 고르고 말한다 | 모든 단어 사이 숨소리 |
| 목 가다듬기 | 말 시작 전에 한 번만 목을 가다듬는다 | 기침과 혼동·반복 |

`performance.nonverbal`에 위치·횟수·강도·대사로 돌아오는 시점을 적는다. 기본 본문 text에 `하하하`, `(기침소리)`를 추가하지 않는다. 원문에 근거가 있는 소리만 넣고, 생성 결과가 말을 바꾸거나 지시를 읽으면 해당 구간만 수정·재생성한다. 비언어 지시의 실제 재현은 확률적이며 청취 검증이 필요하다.

최신 공식 가이드의 새 모델 예시는 `<laugh>`, `<cough>`, `<sigh>`, `<gasp>`, `<short pause>`를 순간 이벤트로, `speech_metadata.style`을 지속 감정으로 구분한다. **이는 기본 2.5 Canvas 경로에서 검증된 태그 목록이 아니다.** `[laughs]` 같은 다른 모델·Cloud 예시도 문법을 혼용하지 않는다. `<small laugh>`·`<sob>` 같은 임의 태그를 공식 지원 태그로 선언하지 않는다. 현재 스킬은 태그를 본문에 자동 삽입하지 않고 자연어 지시를 사용한다. 모델 변경 시에는 호스트 지원·요청 구조·응답 포맷을 모두 별도 시험한다.

## 실용 연기 레시피와 평가

- 억눌린 분노: 낮은 보통 음량, 문장 짧게, 핵심 단어만 단단히. 전 구간 고함 금지.
- 안도 속 슬픔: 첫 숨을 풀고 잠깐 미소, 마지막은 느리지만 단어를 끝까지.
- 기쁨 속 불안: 첫말은 생기 있게, 확인 질문에서 짧게 망설임.
- 냉정한 유혹: 느긋한 리듬, 상대 반응을 기다리는 여백, 웃음을 매 줄 넣지 않음.
- 눈물을 참는 독백: 낮은 정상 발성, 한 번의 작은 흔들림, dry 생성 후 독백에만 기존 DSP.

같은 voice·본문으로 담백/표준/강조 버전을 최대 세 개 비교하되 실제 생성 시험은 Canvas에서 수행한다. 단어 보존, 캐릭터 정체성, 맥락 적합성, 비언어음 횟수, 듣기 편함을 각각 평가한다. 잘된 기준 샘플을 다음 구간의 지시 기준으로 삼되 자동으로 목소리를 복제하지 않는다. 정적 테스트·DSP·모의 실행과 실제 생성·청취·다운로드 완료를 분리해 보고한다.
