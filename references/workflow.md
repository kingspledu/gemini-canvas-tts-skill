# 원문에서 드라마 낭독 대본까지

## 낭독 대상 추출

원문 파일을 읽고 제목·장·장면·대사·서술·독백을 식별한다. 기존 웹소설 페이지라면 실제 각색 본문을 담은 컨테이너를 찾는다. 파우스트 사례는 `.adaptation-intro`, `.adaptation-prose` 안의 문단과 `aside.inner-voice`였다. **다른 사이트에서는 구조를 먼저 조사**하고 같은 선택자를 기계적으로 적용하지 않는다. source/translation details, 메뉴, 버튼, voice-label은 낭독 대상에서 제외한다.

원문 읽기 요청이라면 번역이나 각색을 먼저 만들지 않는다. 원문과 한국어 번역이 병기된 페이지는 사용자가 어느 쪽을 원하는지 세션에서 확인한다. 번역이 필요한데 없으면 기존 내용을 번역인 것처럼 가장하지 않는다.

각 문단이 색인의 어느 구간에 들어갔는지 기록해 누락·중복을 점검한다. 장면 순서와 인과, 화자 전환을 유지한다. 화자를 확정할 수 없는 줄은 앞뒤 문맥과 배역 목록을 더 읽는다. 생성 파일명만 보고 화자를 추정하지 않는다.

## 배역표

한 배역은 한 기본 voice와 persona를 쓴다. persona는 음색의 특성, 말의 속도, 대인 태도, 감정 변화의 범위를 정리한다. 나레이션은 장면을 잇고, 대사는 상대에게 말하고, 독백은 마음속 말을 가까운 거리에서 들려준다. 특정 실존 성우·배우의 목소리를 복제하는 지시 대신 높이·울림·리듬·태도를 구체적으로 적는다.

예: `중저음, 여유 있는 짧은 말끝, 상대를 시험할 때 미소가 느껴짐. 분노해도 소리부터 지르지 않음.`

## 연기 지침

구간별 `emotion`에는 감정의 이유와 변화까지 짧게 적는다. `걱정`만 쓰는 대신 `문 너머의 소리를 듣고 걱정하지만 동생을 안심시키려고 말끝을 다잡음`처럼 쓴다. `acting_notes`에는 상대와 지금 하려는 행동을 적고, `character_state`는 피로·긴장·회상 등의 현재 상태를 적는다.

`pause_after_ms`는 후처리에서 0~3000ms로 제한된다. 문장 중간의 미세한 호흡은 프롬프트로 지시한다. 모든 문장에 한숨·웃음·울음·기침을 기계적으로 붙이지 않는다. 원문이 웃거나 우는 장면이면 실제 짧은 비언어 연기로 표현하되 지시 문구를 말로 읽지 않게 한다. 원문에 없는 기침 사건·비명·음악을 추가하지 않는다.

독백은 나직한 보통 목소리다. 속삭임·성대 울림이 사라진 숨소리·ASMR 입소리는 피한다. 원음으로 생성한 뒤 독백에만 에코를 넣으므로 모델에게 다시 리버브를 연기하라고 지시하지 않는다.

## 출력 검수

원문/선택 본문 ↔ SCRIPT ↔ HTML originalEpisode ↔ 색인을 대조한다. 구간 총수·본문 SHA·화자·voice·파일명 순번·모델·버전을 확인한다. 예전 작품명·전화 인터뷰 설정이 새 작품에 섞이지 않게 한다. HTML의 제목은 HTML escape, 스크립트 안 본문은 `<`를 JSON Unicode escape로 처리해 `</script>`가 코드를 닫지 않게 한다.

키·토큰·로컬 사용자 경로·개인 원고를 공개 저장소에 무심코 넣지 않는다. 스킬 예제는 직접 만든 짧은 글을 사용한다. 사용자가 공개를 요청한 경우에만 실제 원고를 배포한다.
