# Canvas 실행·오디오·다운로드

## 실행 경계

제공 HTML은 키 입력란이 없는 Gemini Canvas 작업 방식으로만 실행한다. Canvas가 내부 음성 생성 요청을 중계하는 경우에만 작동하며, 사용자는 API 키를 입력하지 않는다. `const apiKey = ""`는 인증 우회가 아니다. 일반 로컬 HTML·GitHub Pages에서는 키 없는 음성 생성이 보장되지 않는다. 이 스킬은 API 키 발급·저장·삽입, REST/SDK/CLI 실행, Cloud TTS 전환, 서버 프록시 사용을 하지 않는다. Canvas가 모델을 지원하지 않으면 오류를 기록하고 중단한다.

Canvas에서 생성 HTML의 전체 내용을 붙여 실행형 미리보기로 열고, 한 구간의 생성 버튼으로 호스트 지원 여부를 시험한다. 실제 음성을 듣고 수동 WAV 저장이 되는 것을 확인한 뒤 전체 생성을 시작한다. Canvas가 지원하지 않는다고 확인되면 그 사실과 오류를 알려 주고, 어떤 외부 API·SDK·유료 요청으로도 전환하지 않는다.

기본 모델은 기존 사용자 설정의 raw 16-bit mono PCM 응답을 전제로 한다. mimeType의 rate 값을 읽고, 없으면 24000Hz로 처리한다. 44100Hz로 리샘플하고 WAV를 만든다. 새 모델이 RIFF/WAV·MP3를 반환하면 현재 템플릿은 이를 거부한다. 포맷을 확인해 별도 디코더를 추가하고 시험해야 하며 PCM으로 잘못 해석하지 않는다.

CSS는 Tailwind CDN, 전체 MP3 기능은 lamejs 1.2.1 CDN을 사용한다. MP3 라이브러리는 필요한 시점에 로드된다. 외부 CDN이 막히면 WAV 생성 성공과 MP3 인코더 실패를 구분한다. 단일 HTML이지만 완전 오프라인 실행 파일은 아니다.

## 승인된 독백 효과

이 프로젝트에서 선정한 기본 프리셋: `불안한 독백 · 짧은 에코`.

| 항목 | 값 |
|---|---|
| 리버브 wet | 0.15 |
| decay | 0.55초 |
| pre-delay | 30ms |
| 짧은 에코 | 120ms, gain 0.15 |
| 고역통과 / 저역통과 | 85Hz / 7500Hz |
| 압축 | 없음 |

기본 HTML에 결정론적 모노 DSP가 포함된다. 잔향 꼬리를 음성에 더한 뒤 구간 끝 쉼을 붙여 WAV와 MP3 합치기에 보존한다. narration/dialogue는 DSP를 건너뛴다. 생성기는 kind에 따라 효과를 고정하므로 명칭만 독백인 일반 대사를 만들지 않게 한다. 자동 DSP 검증은 실제 배우 연기의 자연스러움을 증명하지 않는다.

## 저장과 검증

- 자동 다운로드 클릭은 **요청**일 뿐 저장 완료의 증거가 아니다. 차단되면 카드의 `WAV 저장` 링크를 사용자가 직접 누른다.
- 지원되는 환경에서는 폴더 선택 후 WAV와 `.verified.json`을 저장하고 다시 읽어 내용 지문을 확인한다. Canvas에서 폴더 API가 제한되면 일반 다운로드를 사용한다.
- 내려받은 WAV들과 동반 검증 JSON을 선택해 색인·지문·목소리를 검사한다. 파일이 있어도 원고/배역 지문이 다르면 재사용하지 않는다.
- 재시도 JSON에는 누락·실패 구간의 이름·본문·화자·voice·fingerprint가 들어간다. 다른 작품·장·버전의 보고서는 거부해야 한다.
- 전체 MP3 합치기는 현재 장의 색인에 있는 WAV만 사용한다. 이름·순번·샘플레이트가 어긋난 파일을 임의로 끼워 넣지 않는다. 파일명 끝 `(1)`은 중복 다운로드일 수 있으므로 이름만 바꿔 덮어쓰지 말고 본문 지문부터 대조한다.

## 실패를 구분하기

| 증상 | 확인 |
|---|---|
| 생성 요청 자체 실패 | HTTP 오류, 호스트 음성 권한, 모델 지원, 네트워크 |
| 응답 있으나 소리 이상 | mimeType/PCM 바이트 수·샘플레이트·WAV 헤더 |
| 미리듣기는 되나 저장 안 됨 | 다운로드 차단, 수동 링크, 폴더 API 지원 |
| 전체 생성에서만 실패 | 일괄 핸들러의 변수 참조, 구간별 voice와 파일명, 중복 동시 요청 |
| 저장했는데 미완료 표시 | 실제 파일 또는 `.verified.json` 누락, 원고/성우 변경 |
| WAV는 되나 MP3 안 됨 | CDN 차단, 인코더 로드·메모리, 입력 WAV 수와 순서 |

자동 재시도를 무한 반복하지 않는다. 한 구간을 시험하고 동일 원인의 실패가 지속되면 전체 작업을 멈춰 원인을 고친다. 보고할 때 `정적 검증`, `DSP/모의 실행`, `실제 생성`, `청취`, `Canvas 저장`을 구분한다.
